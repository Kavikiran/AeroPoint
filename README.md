# AeroPoint

A computer vision-based virtual mouse system built with Python, OpenCV, and MediaPipe that enables hands-free cursor control through real-time hand gesture recognition, improving accessibility and touchless human-computer interaction.

## 🚀 Features

- 🖱️ Move mouse cursor using hand movement
- 👆 Perform clicks using finger gestures
- ✌️ Smooth and responsive cursor control
- 🎯 Accurate fingertip tracking using MediaPipe
- 💻 Works on Windows, macOS, and Linux
- 🤖 Real-time hand landmark detection
- ⚡ Touchless human-computer interaction

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- Pynput

## 📦 Installation

### Clone the Repository

```bash
git clone https://github.com/Kavikiran/AeroPoint.git
cd AeroPoint
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```
